Aide rapide

Corrigator enregistre toujours vos modifications sur l'appareil courant d'abord. Vous pouvez donc corriger sans réseau. La synchronisation Dropbox est volontairement manuelle (boutons Pull / Push), pour éviter les écrasements non voulus.

Mettre Corrigator hors ligne sur téléphone

L'application est une PWA: vous pouvez l'installer sur l'écran d'accueil.

Android (Chrome, Edge...)

  1. Ouvrez Corrigator dans le navigateur.
  2. Menu du navigateur -> Ajouter à l'écran d'accueil (ou Installer l'application).
  3. Lancez ensuite Corrigator depuis l'icône installée.
  4. Une fois les pages chargées au moins une fois, vous pouvez continuer même sans réseau.

iPhone / iPad (Safari)

  1. Ouvrez Corrigator dans Safari.
  2. Touchez le bouton Partager.
  3. Choisissez Sur l'écran d'accueil.
  4. Ouvrez l'application depuis l'icône: elle fonctionne en local même sans réseau.

Fonctionnement des données locales

  • Toute saisie est enregistrée localement sur l'appareil.
  • Sans internet, vous pouvez continuer à corriger et modifier vos données.
  • Ces changements restent sur l'appareil tant que vous ne faites pas un Push.
  • Le statut de sync affiche si la base locale est plus récente ou non que le cloud.

Communiquer avec Dropbox

La synchronisation n'est pas automatique. C'est vous qui décidez quand envoyer ou récupérer une base. Ce choix est utile pour travailler hors ligne et garder le contrôle entre plusieurs appareils.

Configuration initiale

  1. Cliquez sur le bouton Dropbox dans la barre de navigation.
  2. Renseignez votre token (et éventuellement l'App key), puis testez.
  3. Une fois configuré, les boutons Pull et Push deviennent disponibles.

Que font Push et Pull ?

  • Push: envoie votre base locale vers Dropbox.
  • Pull: remplace la base locale de l'appareil par la version Dropbox.
  • Avant écrasement, Corrigator vous demande confirmation.

Travailler avec 2 appareils (même base)

  1. Sur appareil A: travaillez normalement (même sans réseau), puis faites Push quand vous voulez partager.
  2. Sur appareil B: faites Pull pour récupérer la dernière base du cloud.
  3. Après modifications sur B, faites à nouveau Push.
  4. Revenez sur A et faites Pull pour vous remettre à jour.
